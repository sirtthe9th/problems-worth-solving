# Security policy

## Reporting a vulnerability

If you find a security problem in any code in this repository (a solution's app, a script, a workflow),
**don't open a public issue.** Report it privately:

1. Go to [Security → Report a vulnerability](https://github.com/sirtthe9th/problems-worth-solving/security/advisories/new).
2. Describe the problem, where it is, and how to reproduce it.

The maintainer will acknowledge the report within 7 days, work with the solution lead on a fix, and
credit you when it's published unless you'd rather stay anonymous.

## Abuse, scams and safety

Reports about people rather than code (scams, harassment, attempts to collect personal data) follow
[SAFETY.md](SAFETY.md#how-to-report).

## What's in scope

- Code in `solutions/`, `scripts/` and `.github/`.
- Anything that could expose a solution's users' data.

Live services a solution runs outside this repository are the solution lead's responsibility. Their
`SOLUTION.md` says how to contact them.
